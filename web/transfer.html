File transfer — sender

Drop a file. It is compressed and, if it fits, encoded into one LCR Code symbol carrying its own filename and SHA-256 — point the receiver at it once. A bigger file becomes a fountain: the chunks once, then an endless stream of repair symbols, any slightly-more-than-all of which rebuild the file, so a receiver that misses frames never waits for one to come round again. Nothing is uploaded — it all happens in this tab.

Drop a file or click to choose

One symbol tops out at … after compression — the §9.1 container's 14-bit length field, not the geometry. Auto picks the smallest version that fits, so a small file stays easy to scan. Past that, Auto picks the largest version up to v40 that fits this screen at the module size, and the file is sent as a fountain. Pick a symbol rate the receiver can decode: it gains nothing from symbols it is too slow to read, but losing some costs only a little time.
