LC Code display

Encodes on this device and draws the symbol at exact device pixels. Point the scanner page at it.

For a reliable scan (§13.1): turn the laptop's brightness to maximum, turn off Night Shift / True Tone / any "vivid" colour mode, and leave the symbol still. Keep at least 8 pixels per module — the default 12 is inside the range the spec prefers. Hold the phone slightly off-axis so its own reflection lands away from the symbol (§13.2).
