Why single frames. Frame combining is left off by default because it makes success a function of how long you lingered rather than of where you stood. §12.4's accumulator is the right thing for a real scanner and the wrong thing for a measurement, so turn it on only for a run that is deliberately about it — the mode is recorded either way.

What the rig measures for you. Distance is recorded as captured module pitch — sensor pixels per module — not centimetres, because that is the quantity decoding actually depends on and it needs no tape measure. Angle is recorded as obliquity, the ratio of the coarsest module pitch to the finest across the symbol: 1.0 face-on, climbing as you tilt. Turning it into degrees would need the camera's focal length, which a browser does not expose, so the raw ratio is what gets written down.

Failures are measured too. When a decode fails the page falls back to decoder.probe, which runs detection and the format read only. So a frame that was found but not decoded still contributes its geometry, and only a frame where nothing was found at all is logged without one. That distinction is the whole point: not found and found but marginal are different limits.
